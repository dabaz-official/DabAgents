# DabAgent-Guideline

A collection of rules and guidelines that agents must follow.

This repository is used to consolidate and maintain the conventions agents should adhere to across various tasks, including but not limited to:

- Behavioral principles and collaboration agreements
- Code and documentation style requirements
- Tool usage and security boundaries
- Project-specific workflows

## Usage

Rules are organized by topic. Individual projects can reference or sync content from this repository so that agents load the relevant rules before starting work.
